# Поддержка русского языка в Lipflow (Russian Language Support)

В Lipflow реализована поддержка русского языка с гибридной архитектурой распознавания, окном выбора вариантов (Candidate Review) и защитой от искажений (Guarded Cleanup).

---

## Архитектура и режимы работы

| Режим | Входные данные | Используемая модель | Особенности |
| --- | --- | --- | --- |
| **Quiet Russian (Тихий ввод / Шёпот)** | Микрофон + вебкамера | `faster-whisper` (`large-v3-turbo`, `int8` CPU) + визуальный фильтр MediaPipe | Высокая точность (~99%), микрофон включается только при удержании клавиши и наличии движения губ в кадре. Идеально для повседневной диктовки шёпотом или тихим голосом. |
| **Silent Russian (Чтение по губам без звука)** | Только вебкамера | Auto-AVSR с кириллическим декодером | Полностью беззвучный ввод. Требует обучения/адаптации под лицо и кириллический словарь. |

---

## Быстрый старт

### 1. Установка зависимостей

Для работы тихого режима на русском языке установите модуль `whisper`:

```bash
uv sync --extra russian
```

При первом запуске модель `large-v3-turbo` автоматически загрузится локально (~1.6 ГБ) и будет работать оффлайн.

### 2. Запуск приложения

Запуск в режиме диктовки на русском языке:

```bash
uv run lipflow run --language ru
```

По умолчанию для русского языка активируется тихий режим (`--input-mode whisper`) и политика подтверждения вариантов (`--confidence-policy review`).

Дополнительные параметры:
```bash
# Использование локальной Ollama для исправления текста
uv run lipflow run --language ru --cleanup ollama

# Автоматическая вставка без окна выбора при высокой уверенности
uv run lipflow run --language ru --confidence-policy auto
```

## Окно выбора кандидатов (Candidate Review)

При распознавании фразы поверх экрана появляется компактное окно:
- `1` — вариант с исправлением пунктуации, регистра и контекста (LLM Cleanup);
- `2` — сырое распознавание (Raw transcript);
- `3` — альтернативный вариант из лучевого поиска (Beam hypothesis);
- `Esc` — отмена текущей фразы.

Выбор клавишами `1`, `2` или `3` автоматически возвращает фокус в предыдущее активное окно и вставляет выбранный текст в текущее поле ввода (через эмуляцию ввода Linux uinput или буфер обмена).

---

## Защита от галлюцинаций (Guarded Cleanup)

Модуль `lipflow.guard` автоматически проверяет результаты нейросетевой обработки (Claude / Ollama / Local MLX) и защищает важные элементы речи:
1. **Отрицания:** блокируется случайное удаление или добавление частиц («не», «ни», «нет», «никогда», «нельзя»).
2. **Числа и даты:** речевые числительные («двадцать пять» $\rightarrow$ «25», «тысяча девятьсот сорок третий» $\rightarrow$ «1943») приводятся к стандартному виду, но подмена значений блокируется.
3. **Единицы и валюты:** рубли (`₽`), доллары, евро, проценты, дни недели и месяцы проверяются на совпадение с исходно сказанными словами.

## Тренировка и онбординг на русском языке

Для калибровки детекции губ и тренировки артикуляции в `lipflow` встроены 60 фонетически сбалансированных повседневных русских предложений.

Клипы сохраняются локально в директории:
- `~/.local/share/lipflow/clips/onboarding/ru/` (Linux)
- `%APPDATA%\Lipflow\clips\onboarding\ru\` (Windows)
- `~/Library/Application Support/Lipflow/clips/onboarding/ru/` (macOS)
